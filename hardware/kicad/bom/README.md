# Bill of materials

`cryocooler_bom_digikey.csv` is generated by `tools/gen_bom.py` from the schematic's netlist (so
quantities and designators always match the design). 104 lines, 258 parts per board. Test points are
bare PCB pads and are not in the list.

```bash
python3 hardware/kicad/tools/gen_bom.py     # needs kicad-cli
```

## Importing into Digi-Key

Open Digi-Key's BOM Manager, upload the CSV, and map the columns: `Quantity` -> Quantity,
`Manufacturer Part Number` -> Manufacturer Part Number, `Customer Reference` -> Customer Reference
(designators), `Description` -> Description. Set the number of boards in the BOM Manager (quantities are
per board). Lines without a part number (`MPN basis` = none) need a part picked by hand from the
description and notes.

## How much to trust each part number

| `MPN basis` | Meaning |
|---|---|
| design | the schematic value is the orderable part (ICs, FETs, diodes, inductors, the isolated DC/DC) |
| suggested | picked for the value, package and rating (resistors, capacitors, connectors, LEDs, switch, some ICs' reel suffix). Compare Digi-Key's description with the `Description` column before ordering; I could not check stock or every number against Digi-Key |
| ordered | the substitute actually bought from Digi-Key on 2026-10-15 (see `SUBSTITUTES` in `tools/gen_bom.py`) |
| none | no part found (currently none) |

## JLCPCB assembly files

The same run writes two files for JLCPCB:

* `cryocooler_bom_full.csv`: every part (all 258, through-hole included) in JLCPCB's sample BOM
  format: `Comment`, `Designator` (comma-separated), `Footprint`, `JLCPCB Part #（optional）`. The part
  number column is blank: fill it in `LCSC_PARTS` in `tools/gen_bom.py` (keyed by MPN) or match the
  parts in JLCPCB's BOM upload. MPNs are in the Digi-Key BOM.
* `cryocooler_cpl.csv`: pick-and-place file (`Designator`, `Val`, `Package`, `Mid X`, `Mid Y`,
  `Rotation`, `Layer`; mm, Top/Bottom) for the 240 SMD parts, read from `cryocooler.kicad_pcb` with
  absolute coordinates, the same origin as the Gerbers in `fabrication/`. The 18 through-hole parts
  (J2-J14, JP1-JP5) are not in it; JLCPCB's SMT line does not place them, so hand-solder them or order
  THT assembly.

JLCPCB's part library orients some packages differently from KiCad, so check the placement
preview on the order page and put any fixes in `ROTATION_OFFSETS` (footprint -> degrees).

## Not in the list

* Mating connectors and crimps for J3-J7, J10, J13, J14 (Molex KK 254, JST XH housings and terminals) and the
  cables themselves.
* The Adafruit LSM6DSOX breakout (product 4438) that plugs into J14 through an 8-wire cable (J14 pins 1-8 match its pads, top to bottom); it replaces the
  on-board LSM6DSOXTR (U19), which is no longer on the board.
* A fuse at the supply end (see `DESIGN_REVIEW.md`), spares and overage, mounting hardware for the four
  M3 holes, and any heatsinking for Q1 (D2PAK).

## Notes that affect what you order

* R65, the 15 mOhm shunt, dissipates about 1.5 W at 10 A: use 2 W or more (WSL2512R0150FEA18 is 2 W).
* U3 (SG-8002CA) is listed as not for new designs at Digi-Key; it is the part the schematic uses.
* L1 is ordered as the shielded Bourns SRP6050CA-4R7M (4.7 uH, 18.4 mOhm max, Isat 10.5 A) instead of the
  SRN6045TA-4R7M the footprint was drawn for. Its terminals (about 1.25-2.65 mm from centre) land inside the
  2.35 x 5.1 mm pads and the 6.6 x 6.4 mm body fits the courtyard, but the footprint is unchanged: solder the
  first one by hand and check it. The schematic value and `cryocooler_bom_full.csv` still say SRN6045TA.
* D11 uses Adafruit 1655 because Digi-Key has no WorldSemi WS2812B; Adafruit says it is hand-solder only.
* C68 (100 pF C0G): Digi-Key marks the Samsung CL31C101JBCNNNC obsolete; use Kemet C1206C101J5GACTU or similar.
* D3, D4, D12 (bicolor): SunLED XZMDKVG55W-4, a 2-pin anti-parallel 1206 part; check the standby LED's current stays under 30 mA.
* F1 is the Littelfuse NANO2 453 5 A fast-acting fuse (2410 footprint); no 5 A fast-acting fuse exists in 1812.
* R44 (3.9 k, the ADS1220 reference resistor) should be 0.1 % and low drift; measure it and set
  `PT1000_REF_R` in `include/config/config.h` (it is 3854 now).
* Capacitor voltage ratings: 25 V parts on the 12 V and +/-15 V rails, 50 V on the +/-16.5 V rails, and
  consider 35 V for C6 on the input rail.
* U10: check the EMC2303 suffix gives the 0x4D address with the 33 k ADDR_SEL resistor.

## Mouser (the lines Digi-Key could not supply)

`cryocooler_bom_mouser.csv` lists the 8 lines with no Digi-Key stock: L1, PS1, U1, U3, U9, U15, U19, U23.
Import it in Mouser's BOM tool (MPN and quantity columns) to see live stock. Mouser blocks automated
lookups, so stock was **not** verified; the Mouser part numbers come from search snapshots and some were
months old.

* U9: the real part is **OPA188AID** (reel OPA188AIDR); the schematic value "OPA188ID" is not an orderable
  number, and Digi-Key's substitute OPA180ID is a different op-amp.
* U3: the PHBB oscillator is discontinued; PHCLX is the same part at +/-100 ppm.
* PS1: Digi-Key named MIE1W0505BGLVH-3R-P as a direct substitute for -3R-Z if Mouser is out.
* U23: if the INA239 is unobtainable, the INA229 (20-bit) has the same package but a different register
  map and needs firmware changes.
