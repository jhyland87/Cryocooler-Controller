Firmware Update

Upload a compiled .bin to flash the cryocooler controller over WiFi.

⚠ Safety notice: The system must be in Idle or Off state before uploading. A successful update reboots the MCU immediately — a running cryocooler will stop without a controlled shutdown ramp.
FYI: This can be done via the CLI with:

pio run -e esp32s3 && curl -vF "firmware=@.pio/build/esp32s3/firmware.bin" http://cryocooler.local/ota

Or, from the project root:

bash scripts/ota-update.sh
