# Style Guide

Coding conventions for this repository, split by language so each loads only
for the code it covers. Match the surrounding code, and prefer an existing
pattern over inventing a new one.

| Code | Guide |
|------|-------|
| C++ firmware (`src/`, `include/`, `test/`) | [`docs/style/cpp.md`](docs/style/cpp.md) |
| TypeScript dashboard (`dashboard/`) | [`docs/style/typescript.md`](docs/style/typescript.md) |
